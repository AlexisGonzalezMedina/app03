Calculadora de Divisas

Es una aplicación web para realizar conversiones entre distintas divisas en tiempor real.

Propósito
El proposito de este proyecto es ofrecer una herramienta financiera simplificada que permita a los usuarios calcular diferentes montos en monedas extranjeras. 

Tecnologías Utilizadas
HTML semántico: Estructura semántica del convertidor.
CSS: Diseño responsivo para movil (480px), tablet(768px) y desktop(1024px), uso de variables de CSS ":root"
JavaScript: Captura valores de los inputs con document.getElementById, Realizar los cálculos usando funciones separadas, Muestra los resultados actualizando el DOM con innerHTML, utiliza condiciones (if/else) y utiliza un objeto.
